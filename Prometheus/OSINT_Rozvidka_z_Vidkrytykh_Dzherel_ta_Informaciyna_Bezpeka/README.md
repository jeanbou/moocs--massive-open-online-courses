# Prometheus курси - Пройдені модулі та відповіді до курсу OSINT - Open Source Intelligence

## Опис курсу

Назва курсу: OSINT - Open Source Intelligence  

Посилання на курс:  
https://prometheus.org.ua/prometheus-free/osint-open-source-intelligence/

Цей курс присвячений розвідці з відкритих джерел (OSINT) та інформаційній безпеці. Він навчає ефективно збирати, аналізувати та використовувати публічно доступні дані.

Основні теми курсу:

- Збір інформації з відкритих джерел (соціальні мережі, реєстри, новини)  
- Виявлення фейків та дезінформації  
- Захист персональних даних  
- Виявлення загроз та запобігання витокам інформації  
- Використання OSINT-інструментів на практиці
