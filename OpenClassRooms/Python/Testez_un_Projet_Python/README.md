# Testez votre projet avec Python - OpenClassrooms

This repository contains answers and notes for the OpenClassrooms course:

Testez votre projet avec Python

Course link:  
https://openclassrooms.com/fr/courses/4425126-testez-votre-projet-avec-python

---

## Présentation du cours

Ce cours vous apprend à **tester un projet Python de manière efficace et automatisée**.

Vous découvrez pourquoi les tests sont essentiels dans le développement logiciel afin de :

- Réduire les bugs  
- Sécuriser le code lors des évolutions  
- Améliorer la qualité globale du projet  
- Faciliter la maintenance  

Le cours introduit les différents types de tests et les bonnes pratiques associées.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Écrire des tests unitaires en Python  
- Utiliser Pytest pour tester une application  
- Mettre en place des tests d’intégration  
- Comprendre les tests fonctionnels et de performance  
- Appliquer le Test-Driven Development (TDD)  
- Améliorer la fiabilité d’un projet Python  

---

## Structure du cours

### 1. Introduction aux tests
- Pourquoi tester un projet  
- Types de bugs et erreurs  
- Importance de l’automatisation  

### 2. Tests unitaires
- Écriture de tests simples  
- Organisation des tests  
- Utilisation de unittest et pytest  

### 3. Tests avancés avec Pytest
- Utilisation des fixtures  
- Mocking et simulation d’objets  
- Tests d’applications web (Flask / Django)  

### 4. Tests avancés
- Tests d’intégration  
- Tests fonctionnels  
- Tests de performance avec Locust  
- Introduction au TDD
