# Démarrez votre projet avec Python - OpenClassrooms

This repository contains answers and notes for the OpenClassrooms course:

Démarrez votre projet avec Python

Course link:  
https://openclassrooms.com/fr/courses/4262331-demarrez-votre-projet-avec-python

---

## Présentation du cours

Ce cours vous apprend à **démarrer correctement un projet en Python**, en adoptant de bonnes pratiques dès le début du développement.

Vous découvrez comment structurer un projet, organiser votre code et mettre en place un environnement de travail propre et efficace.

L’objectif est de passer de simples scripts Python à de **vrais projets structurés et maintenables**.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Comprendre comment structurer un projet Python  
- Mettre en place un environnement de développement adapté  
- Organiser son code de manière propre et évolutive  
- Appliquer des bonnes pratiques dès le début d’un projet  
- Préparer un projet pour le travail en équipe ou en production  

---

## Structure du cours

### 1. Introduction au projet Python
- Pourquoi structurer un projet  
- Différence entre script et projet  

### 2. Mise en place de l’environnement
- Installation des outils nécessaires  
- Configuration de l’environnement Python  

### 3. Organisation du code
- Structure de fichiers et dossiers  
- Bonnes pratiques de séparation du code  

### 4. Bonnes pratiques de développement
- Code lisible et maintenable  
- Préparation à l’évolution du projet  
- Introduction aux workflows professionnels
