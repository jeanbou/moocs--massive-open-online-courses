# Apprenez a programmer en Python - OpenClassrooms

Ce repository contient les reponses et notes pour le cours OpenClassrooms :

Apprenez a programmer en Python

Lien du cours :  
https://openclassrooms.com/fr/courses/235344-apprenez-a-programmer-en-python

---

## Presentation du cours

Ce cours vous initie aux **bases de la programmation avec Python**, un langage simple, puissant et tres utilise dans le developpement logiciel, la data science, l automation et l intelligence artificielle.

Python est un langage ideal pour debuter car il permet d apprendre les concepts fondamentaux de la programmation sans complexite excessive.

Vous apprendrez a penser comme un developpeur et a construire vos premiers programmes.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre les bases de la programmation  
- Utiliser les variables et les types de donnees  
- Ecrire des conditions (if / else)  
- Utiliser les boucles (for / while)  
- Creer des fonctions  
- Resoudre des problemes simples en Python  

---

## Structure du cours

Le cours est organise progressivement pour faciliter l apprentissage :

### 1. Introduction a la programmation
- Qu est-ce que programmer  
- Presentation de Python  
- Installation et environnement de travail  

### 2. Les bases de Python
- Variables et types de donnees  
- Conditions  
- Boucles  

### 3. Fonctions et logique
- Creation de fonctions  
- Organisation du code  
- Resolution de problemes simples  

### 4. Exercices pratiques
- Petits exercices de programmation  
- Applications concretes  
- Entrainement progressif
