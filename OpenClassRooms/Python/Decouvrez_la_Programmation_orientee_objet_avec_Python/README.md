## Presentation du cours

Ce cours vous introduit a la **programmation orientee objet (POO) avec Python**, un paradigme fondamental du developpement logiciel moderne.

La POO permet de structurer le code autour d’**objets**, afin de rendre les programmes plus clairs, modulaires et reutilisables.

Cette approche est utilisee dans la plupart des logiciels modernes, des applications web aux systemes complexes.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre les bases de la programmation orientee objet  
- Creer des classes et des objets en Python  
- Utiliser les attributs et les methodes  
- Comprendre l encapsulation  
- Utiliser l heritage pour reutiliser du code  
- Structurer une application Python de maniere modulaire

## Structure du cours

Le cours est organise en plusieurs parties :

### 1. Comprendre les bases de la POO
- Definition des objets et des classes

### 2. Les classes et les objets
- Creation de classes en Python  
- Instanciation d objets  
- Utilisation des attributs et methodes  

### 3. Les principes fondamentaux
- Encapsulation  
- Heritage  
- Organisation du code  

### 4. Application pratique
- Exercices de programmation orientee objet  
- Structuration d un petit projet Python
