## Course Overview

Do you write code and work with other developers?  
Do you want to track changes to your code and avoid losing your work?

Version control is essential in modern software development.

This course introduces **Git**, a powerful version control system created by Linus Torvalds, and **GitHub**, a platform for hosting and collaborating on code.

You will explore key concepts such as:

- Tracking changes in your code  
- Managing versions safely  
- Collaborating with other developers  
- Contributing to open source projects  

By the end of the course, you will understand how to work efficiently with Git in real-world development environments.

---

## What You Will Learn

In this course, you will learn how to:

- Initialize and manage a Git repository  
- Create commits and track changes  
- Work with branches and merges  
- Resolve conflicts  
- Use GitHub for collaboration  
- Share and contribute to projects
