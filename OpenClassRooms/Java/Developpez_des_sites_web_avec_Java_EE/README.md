# Developpez des sites web avec Java EE - OpenClassrooms

Ce repository contient les reponses et notes pour le cours OpenClassrooms :

Developpez des sites web avec Java EE

Lien du cours :  
https://openclassrooms.com/fr/courses/2434016-developpez-des-sites-web-avec-java-ee

---

## Presentation du cours

Vous etes etudiant de l’enseignement superieur dans un cursus scientifique (ingenieur, universite) ?  
Vous souhaitez debuter ou approfondir vos connaissances en Java EE ?  
Ou vous avez besoin d’une remise a niveau sur cette technologie ?

Ce cours vous permet de comprendre et de maitriser le developpement d’applications web en Java EE.

Vous apprendrez notamment :

- Ce qu’est Java EE et son ecosysteme  
- Comment installer un environnement de developpement  
- Les bonnes pratiques utilisees dans l’industrie  
- La creation de Servlets et de JSP  
- L’utilisation de la JSTL  
- L’acces aux bases de donnees avec JDBC et DAO  

A travers une presentation interactive et des exercices pratiques, vous serez capable de developper des applications web completes en suivant l’architecture MVC (Modele, Vue, Controleur).

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre l’architecture d’une application Java EE  
- Developper des Servlets et des JSP  
- Structurer une application web avec le pattern MVC  
- Interagir avec une base de donnees via JDBC et DAO  
- Appliquer les bonnes pratiques du developpement web Java
