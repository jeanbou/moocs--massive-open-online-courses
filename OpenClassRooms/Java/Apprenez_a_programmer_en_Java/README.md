## Presentation du cours

Ce cours vous permet de decouvrir les bases de la programmation avec l'un des langages les plus populaires : Java.

Vous apprendrez progressivement a ecrire vos premiers programmes et a comprendre comment fonctionne un logiciel. Le cours commence par les fondamentaux puis evolue vers des concepts plus avances comme la programmation orientee objet. :contentReference[oaicite:0]{index=0}

Les principaux themes abordes sont :

- Les variables et types de donnees  
- Les conditions et les boucles  
- Les fonctions  
- La programmation orientee objet (classes, heritage, polymorphisme)  
- Les collections de donnees  
- Les notions avancees (exceptions, fichiers, lambda, etc.)  

Ce cours est ideal pour debuter en programmation et construire des bases solides en Java.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Gerer les variables et la logique d'un programme  
- Ecrire des programmes simples en Java  
- Comprendre et appliquer la programmation orientee objet  
- Utiliser des concepts avances pour ameliorer vos programmes :contentReference[oaicite:1]{index=1}
