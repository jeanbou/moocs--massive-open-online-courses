## Presentation du cours

Ce cours vous permet de comprendre et de maitriser la **programmation reseau en Java**, un domaine essentiel pour developper des applications capables de communiquer entre plusieurs machines.

Vous apprendrez comment Java permet de travailler avec les reseaux et de construire des applications distribuees.

Les principaux sujets abordes sont :

- Les bases des reseaux informatiques  
- Le fonctionnement des communications client/serveur  
- Les sockets en Java  
- La creation d'applications reseau simples  
- L'echange de donnees entre machines  
- Les bonnes pratiques de programmation reseau  

Ce cours vous aide a comprendre comment des applications peuvent communiquer a travers Internet ou un reseau local.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre les concepts de base des reseaux  
- Utiliser les sockets en Java  
- Creer des applications client/serveur  
- Gerer les communications entre machines  
- Developper des applications reseau simples et fonctionnelles
