# Reprenez le controle a l'aide de Linux - OpenClassrooms

Ce repository contient les reponses et notes pour le cours OpenClassrooms :

Reprenez le controle a l'aide de Linux

Lien du cours :  
https://openclassrooms.com/fr/courses/43538-reprenez-le-controle-a-l-aide-de-linux

---

## Presentation du cours

"Linux c'est trop complique, c'est pour les pros"

Dire qu'il y a encore des gens qui pensent ca !

Mais non, Linux n'est pas complique, et ce cours est la pour le prouver.

Ce cours est concu pour les debutants et commence depuis les bases absolues afin de vous aider a comprendre et utiliser Linux sans difficulte.

Vous allez decouvrir un nouveau systeme d'exploitation, puissant, libre et totalement gratuit.

---

## A qui s'adresse ce cours ?

Ce cours est adapte a :

- Les utilisateurs de Windows qui veulent decouvrir Linux  
- Les debutants sous Linux qui veulent mieux comprendre leur systeme  
- Les webmasters qui administrent des serveurs Linux  
- Les curieux qui veulent comprendre comment fonctionne Linux  
- Toute personne souhaitant reprendre le controle de son environnement informatique  

Linux permet aujourd'hui de reprendre le controle de son ordinateur et de decouvrir un ecosysteme riche et passionnant, sans depenser d'argent.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre le fonctionnement de base de Linux  
- Utiliser le terminal pour executer des commandes  
- Gerer les fichiers et repertoires sous Linux  
- Installer et administrer un systeme Linux  
- Comprendre les bases de l'administration systeme
