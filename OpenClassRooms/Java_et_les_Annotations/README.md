## Presentation du cours

Ce cours vous permet de comprendre et de maitriser les **annotations en Java**, une fonctionnalite introduite avec Java 5.

Les annotations permettent d'ajouter des **metadonnees** au code (classes, methodes, variables, etc.), facilitant ainsi la configuration, la documentation et l'automatisation de certaines taches. :contentReference[oaicite:0]{index=0}

Elles sont largement utilisees dans les frameworks modernes (Spring, JPA, etc.) pour :

- Simplifier la configuration  
- Reduire le code repetitif (boilerplate)  
- Automatiser des comportements a l'execution ou a la compilation  
- Ameliorer la lisibilite du code  

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre le role des annotations en Java  
- Utiliser les annotations standards  
- Creer vos propres annotations  
- Exploiter les annotations avec la reflection  
- Comprendre leur utilisation dans les frameworks
