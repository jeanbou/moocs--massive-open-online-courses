## Présentation du cours

Ce cours vous introduit aux **fondamentaux du référencement naturel (SEO)** et aux stratégies permettant d’améliorer la visibilité d’un site web sur les moteurs de recherche comme Google.

Le SEO (Search Engine Optimization) est un ensemble de techniques visant à :

- Améliorer le positionnement d’un site dans les résultats de recherche  
- Augmenter le trafic organique (non payant)  
- Attirer des visiteurs qualifiés  
- Optimiser la structure et le contenu d’un site web  

Ce cours vous aide à comprendre comment construire une stratégie SEO efficace et durable.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Comprendre les bases du référencement naturel  
- Identifier les facteurs clés de classement sur Google  
- Optimiser le contenu d’un site web pour le SEO  
- Choisir les bons mots-clés  
- Améliorer la visibilité et le trafic organique  
- Construire une stratégie SEO cohérente

### 1. Comprendre le fonctionnement du SEO

### 4. Améliorer la visibilité d’un site
