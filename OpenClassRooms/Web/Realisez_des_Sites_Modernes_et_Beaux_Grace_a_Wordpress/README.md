## Présentation du cours

Ce cours vous apprend à **créer des sites web modernes et attractifs avec WordPress**, sans avoir besoin de coder côté serveur.

WordPress est une plateforme extrêmement populaire, utilisée par une grande partie des sites web dans le monde. Il offre une solution simple et rapide pour créer des sites professionnels.

Dans ce cours, vous serez guidé pas à pas pour :

- Installer WordPress  
- Configurer un site web  
- Personnaliser le design  
- Ajouter des fonctionnalités  

Le tout de manière claire, accessible et efficace.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Installer et configurer WordPress  
- Créer et gérer du contenu (pages, articles)  
- Personnaliser un site avec des thèmes  
- Ajouter des fonctionnalités avec des plugins  
- Construire un site web professionnel sans coder  
- Mettre en ligne un site rapidement
