# Comprenez votre audience avec Google Analytics - OpenClassrooms

This repository contains answers and notes for the OpenClassrooms course:

Comprenez votre audience avec Google Analytics

Course link:  
https://openclassrooms.com/fr/courses/3013736-comprenez-votre-audience-avec-google-analytics

---

## Présentation du cours

Ce cours vous initie aux **bases du Web Analytics** et à l’utilisation de **Google Analytics** pour comprendre le comportement des visiteurs d’un site web.

Vous apprendrez à collecter, analyser et interpréter des données afin d’améliorer en continu la performance de vos actions marketing.

L’objectif est de passer de simples hypothèses à une **prise de décision basée sur les données**.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Comprendre les bases du Web Analytics  
- Configurer et utiliser Google Analytics  
- Analyser le trafic d’un site web  
- Comprendre le comportement des utilisateurs  
- Tester des hypothèses à partir des données  
- Améliorer les performances d’un site ou d’une application  

---

## Structure du cours

### 1. Les bases du Web Analytics
- Qu’est-ce que le Web Analytics  
- Mise en place d’un plan de mesure  
- Configuration de Google Analytics  

### 2. Explorer les données avec Google Analytics
- Analyse de l’audience  
- Étude des sources de trafic  
- Comportement des visiteurs  
- Analyse des conversions  

### 3. Interpréter les données
- Formulation d’hypothèses  
- Tests et analyses  
- Optimisation continue des performances
