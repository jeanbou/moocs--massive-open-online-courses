## Présentation du cours

Ce cours vous permet de découvrir **le cloud computing** et d’apprendre à **déployer un site web sur Google App Engine**, une plateforme cloud puissante.

Le cloud est aujourd’hui incontournable dans le développement moderne. Il permet d’héberger des applications sur des infrastructures distantes sans gérer les serveurs.

Avec Google App Engine, vous pouvez :

- Héberger votre site sur les serveurs de Google  
- Bénéficier d’une infrastructure scalable automatiquement  
- Gérer facilement la montée en charge de votre application  
- Vous concentrer sur le code plutôt que sur l’infrastructure :contentReference[oaicite:0]{index=0}  

Ce cours vous guide pas à pas dans la découverte et l’utilisation de cette technologie.

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Comprendre le concept de cloud computing  
- Déployer une application sur Google App Engine  
- Gérer les données dans le cloud  
- Utiliser les services proposés par Google Cloud  
- Construire une application web scalable  

---

## Structure du cours

### 1. Débutez avec Google App Engine
- Qu’est-ce que le cloud  
- Présentation de Google App Engine  
- Installation et configuration  
- Création et déploiement d’une première application  

### 2. Stockez vos données dans le cloud
- Introduction aux bases de données cloud  
- Google Cloud SQL  
- Datastore (NoSQL)  
- Google Cloud Storage  

### 3. Utilisez les services App Engine
- Authentification avec Google Accounts API  
- Envoi d’emails avec Mail API  
- Manipulation d’images  
- Automatisation avec les tâches planifiées (cron)  
- Création d’API avec Cloud Endpoints
