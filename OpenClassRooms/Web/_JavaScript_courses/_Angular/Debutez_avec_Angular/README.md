## Présentation du cours

Ce cours constitue **une introduction complète au framework Angular**, utilisé par des milliers d’entreprises pour développer des applications web modernes. :contentReference[oaicite:0]{index=0}

Si vous maîtrisez déjà HTML, CSS et JavaScript, Angular vous permet de passer à l’étape suivante : créer des applications web **structurées, dynamiques et professionnelles**.

Tout au long du cours, vous allez construire une application de A à Z afin de pratiquer les concepts fondamentaux d’Angular :

- Les components  
- Le data binding (liaison de données)  
- Les événements  
- Les directives et pipes  
- Les services  
- Le routing (navigation) :contentReference[oaicite:1]{index=1}  

---

## Objectifs du cours

À la fin de ce cours, vous serez capable de :

- Créer une application Angular complète  
- Construire et organiser des components  
- Gérer l’affichage et les interactions avec le data binding  
- Structurer une application avec des directives et des pipes  
- Partager des données avec des services  
- Mettre en place une navigation avec le routing :contentReference[oaicite:2]{index=2}

## Structure du cours

### 1. Préparer le terrain pour Angular
- Découverte du framework  
- Installation des outils (Angular CLI)  
- Création d’un projet Angular  

### 2. Construire des components
- Création de components  
- Affichage des données  
- Gestion des événements  

### 3. Structurer l’application
- Directives (conditions, boucles)  
- Gestion du style dynamique  
- Organisation du code  

### 4. Transformer les données
- Utilisation des pipes  
- Formatage des données (dates, nombres, texte)  

### 5. Améliorer l’architecture
- Services pour partager les données  
- Centralisation de la logique métier  
- Routing pour créer une SPA (Single Page Application)
