## Course Overview

This course introduces **jQuery**, one of the most widely used JavaScript libraries in front-end web development.

jQuery simplifies JavaScript programming by providing an easy way to:

- Manipulate HTML elements  
- Create animations and visual effects  
- Handle user interactions  
- Perform dynamic style changes  
- Build interactive and responsive user interfaces  

With jQuery, you can quickly add effects such as:

- Color changes  
- Fade in / fade out animations  
- Element transitions  
- Dynamic content updates  

The combinations are almost endless, making jQuery a powerful tool for enhancing user experience on web pages.

---

## Why Learn jQuery?

Even though modern frameworks exist today, jQuery remains important because it:

- Helps understand core DOM manipulation concepts  
- Is still widely used in legacy projects  
- Provides a simple API for common JavaScript tasks  
- Strengthens your foundation in front-end development  

By learning JavaScript fundamentals first and then jQuery, you build a strong base for future frameworks and tools.

## Objectives of the Course

By the end of this course, you will be able to:

- Understand what jQuery is and why it is used  
- Select and manipulate HTML elements easily  
- Apply visual effects and animations  
- Handle events such as clicks and inputs  
- Improve user interaction on web pages  
- Write cleaner and shorter JavaScript code using jQuery
