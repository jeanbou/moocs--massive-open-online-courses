## Presentation du cours

Ce cours vous apprend a utiliser **Apache Maven**, un outil essentiel pour les developpeurs Java permettant d'organiser, construire et automatiser les projets logiciels.

Apache Maven permet notamment de :

- Gerer les dependances automatiquement  
- Structurer les projets Java de maniere standardisee  
- Automatiser la compilation, les tests et le packaging  
- Generer des livrables fiables (JAR, WAR, etc.)  

Le cours couvre egalement l'integration avec des IDE comme Eclipse ou IntelliJ, ainsi que la gestion de projets multi-modules. :contentReference[oaicite:0]{index=0}

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Creer et configurer un projet Maven  
- Comprendre le cycle de vie Maven  
- Gerer efficacement les dependances  
- Utiliser et configurer des plugins Maven  
- Automatiser la construction de vos applications  
- Generer des rapports et un site projet
