## Presentation du cours

Ce cours vous permet de comprendre et de maitriser l’utilisation du **XML avec Java**, un format de donnees largement utilise pour l’echange et la structuration d’informations.

Vous apprendrez comment Java permet de manipuler des fichiers XML de maniere efficace, en lecture comme en ecriture.

Les principaux sujets abordes sont :

- Introduction au format XML  
- Structure et syntaxe d’un document XML  
- Validation avec DTD et XSD  
- Parsing de fichiers XML en Java  
- API Java pour le traitement XML (DOM, SAX, StAX, JAXP)  
- Generation et transformation de documents XML  

XML est un standard important pour l’interoperabilite entre systemes informatiques.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre la structure d’un document XML  
- Lire et manipuler des fichiers XML en Java  
- Utiliser les principales API de parsing XML  
- Choisir la bonne approche (DOM, SAX ou StAX) selon le besoin  
- Generer et transformer des donnees XML
