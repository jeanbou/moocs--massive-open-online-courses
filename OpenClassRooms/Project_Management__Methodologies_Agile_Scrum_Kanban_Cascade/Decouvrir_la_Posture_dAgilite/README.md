## Presentation du cours

Ce cours vous permet de comprendre ce qu est la **posture d agilite**, un etat d esprit essentiel dans les environnements professionnels modernes.

Avec la transformation digitale, les entreprises doivent s adapter rapidement aux changements. L agilite ne se limite pas a une methode (comme Scrum), mais repose avant tout sur une facon de penser et de travailler. :contentReference[oaicite:0]{index=0}

Vous decouvrirez :

- Les principes fondamentaux de l agilite  
- Les changements dans les modes de travail des equipes  
- Les benefices de l agilite (rapidite, efficacite, collaboration)  
- Les difficultes d adaptation au changement  
- L importance de l etat d esprit agile  

Ce cours met l accent sur la dimension humaine et collaborative de l agilite.

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre ce qu est une posture agile
