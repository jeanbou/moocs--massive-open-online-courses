## Presentation du cours

Ce cours vous apprend a **bien cadrer un projet multimedia**, une etape essentielle pour assurer sa reussite.

Le cadrage est une phase cle qui permet de definir clairement les objectifs, les besoins du client et le perimetre du projet avant de commencer sa realisation.

Un bon cadrage permet d'eviter :

- Les incomprehensions avec le client  
- Les depassements de budget  
- Les retards de planning  
- Les modifications non maitrisees  

Vous apprendrez a poser des bases solides pour garantir le bon deroulement du projet.

---

## Objectifs du cours

A la fin de ce cours, vous serez capable de :

- Comprendre l'importance du cadrage dans un projet  
- Identifier les besoins du client  
- Definir le perimetre du projet  
- Rediger un cahier des charges clair  
- Structurer les objectifs et les livrables  
- Anticiper les risques
