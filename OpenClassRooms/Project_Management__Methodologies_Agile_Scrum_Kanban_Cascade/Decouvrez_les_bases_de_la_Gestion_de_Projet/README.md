## Presentation du cours

Ce cours vous permet de comprendre les **fondamentaux de la gestion de projet**, une competence essentielle dans de nombreux domaines (IT, web, marketing, etc.).

Vous apprendrez a structurer, planifier et piloter un projet de maniere efficace, depuis l'idee initiale jusqu'a sa realisation finale.

La gestion de projet permet notamment de :

- Definir des objectifs clairs  
- Organiser les taches et les ressources  
- Coordonner une equipe  
- Respecter les delais et le budget  
- Evaluer les resultats

## Objectifs du cours

A la fin de ce cours, vous serez capable de :
